# Reference documents — how to (re)populate docs/refs/

> **This folder is git-ignored on purpose.** The files here are third-party
> copyrighted documents, forum posts, and vendor source files — kept local
> only, never committed/published. Only this markdown is tracked. Use the
> links below to refill the folder on a fresh checkout. Filenames in
> backticks are what the code/notes expect; a few are auto-generated by our
> extraction steps (see "Extraction" at the bottom).

## Layout (since 2026-10-16; CAN folders since 2026-10-21)

Each `NOTES.md` / `CAN-NOTES.md` is a locally written, source-cited digest (also git-ignored).
The `dl` lines below write into the subfolder named in the comment above each group.

- https://github.com/Elmue/CANable-2.5-firmware-Slcan-and-Candlelight (the adapter's stock firmware + host classes)

- https://github.com/jxltom/gs_usb (pypi gs_usb; python-can's gs_usb backend uses it)
- https://github.com/hardbyte/python-can
- https://github.com/patagonaa/huawei-r48xx (best Huawei R48xx protocol write-up) and
  https://github.com/craigpeacock/Huawei_R4850G2_CAN (reference SocketCAN tool)
- https://github.com/dalathegreat/Battery-Emulator (PYLON-LV-CAN emitter), https://github.com/stuartpittaway/diyBMSv4ESP32
  (pylon/victron emitters), https://github.com/hoylabs/OpenDTU-OnBattery (Pylontech CAN receiver)
- https://github.com/grericht/dyness-bms-esphome-canbus (Dyness CAN decoder incl. native 0x18AA/0x18BB frames)
- https://github.com/ArminJo/JK-BMSToPylontechCAN (0x379 capacity frame for LuxPower SNA)
